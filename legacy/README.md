# Earlier Fieldkit implementations

The Python 0.4 runtime, its tests and packaging metadata, the native C++ Handlecheck engine, and historical docs are retained here as migration/reference material. The current Cargo package never imports or launches them. Their original paths in historical docs are intentionally historical; use git history for the complete earlier build layout.

Current runtime, development commands, and investigation workflow are documented at the repository root. Existing v1 case ledgers and workspace records are read directly by the Rust runtime.
